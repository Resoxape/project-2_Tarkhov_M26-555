# primitive_db

Примитивная консольная база данных на Python. Позволяет создавать и удалять
таблицы со столбцами типов `int`, `str`, `bool` и выполнять над данными
CRUD-операции (`insert`, `select`, `update`, `delete`). Метаданные таблиц
хранятся в `db_meta.json`, данные каждой таблицы — в `data/<таблица>.json`.
Проект написан в процедурном стиле, оформлен как uv-пакет и устанавливается
как консольная команда `database`.

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)
- make (необязательно — все команды можно запускать через `uv` напрямую)

## Установка и запуск

| Действие | uv | make |
|---|---|---|
| Установить зависимости | `uv sync` | `make install` |
| Запустить базу данных | `uv run database` | `make run` |
| Проверить код линтером | `uv run ruff check .` | `make lint` |
| Собрать пакет | `uv build` | `make build` |
| Установить пакет как команду | `uv tool install --force dist/primitive_db-1.0.0-py3-none-any.whl` | `make package-install` |

После установки пакета база данных запускается из любой директории командой:

```
database
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.
Столбец `ID:int` добавляется в начало каждой таблицы автоматически.

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя>` | удалить таблицу (с подтверждением) |
| `help` | справочная информация |
| `exit` | выход из программы |

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users
```

## CRUD-операции

Строковые значения пишутся в кавычках, `bool` — как `true`/`false`.
`ID` генерируется автоматически и в `insert` не передаётся; все поля обязательны.

| Команда | Описание |
|---|---|
| `insert into <таблица> values (<значение1>, <значение2>, ...)` | создать запись |
| `select from <таблица>` | прочитать все записи |
| `select from <таблица> where <столбец> = <значение>` | прочитать записи по условию |
| `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` | обновить записи |
| `delete from <таблица> where <столбец> = <значение>` | удалить записи (с подтверждением) |
| `info <таблица>` | информация о таблице |

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
Функция insert выполнилась за 0.000 секунд.

>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок, подтверждение действий и кэширование

Модуль `decorators.py`:

| Инструмент | Что делает | Где применён |
|---|---|---|
| `handle_db_errors` | перехватывает `KeyError`, `ValueError`, `FileNotFoundError` и прочие исключения и выводит понятное сообщение вместо падения программы | функции `core.py`, обработчики команд в `engine.py` |
| `confirm_action(action_name)` | запрашивает подтверждение `[y/n]`; любой ответ, кроме `y`, отменяет операцию | `drop_table`, `delete` |
| `log_time` | выводит время выполнения функции | `select`, `insert` |
| `create_cacher()` | замыкание со словарём-кэшем: одинаковые запросы `select` не читают файл повторно | `select` |

Кэш учитывает версию файла данных, поэтому после `insert`, `update` или
`delete` повторный `select` всегда возвращает актуальные записи. Если результат
взят из кэша, строка с временем выполнения не выводится.

```
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.

>>>Введите команду: select from users where salary = 100
Ошибка: Столбца "salary" нет в таблице "users".
```

## Структура проекта

```

├── __init__.py
├── main.py         # точка входа
├── engine.py       # основной цикл, обработка ввода и вызов команд
├── core.py         # таблицы и CRUD-операции
├── parser.py       # разбор команд и условий where, set, values
├── utils.py        # загрузка и сохранение метаданных и данных таблиц
├── decorators.py   # декораторы и замыкание для кэширования
└── constants.py    # константы
```
